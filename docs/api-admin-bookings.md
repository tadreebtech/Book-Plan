# API бронирований для администратора

Все методы доступны только аутентифицированному активному пользователю с ролью `ADMIN`.
Префикс API: `/api/v1/`. Методы только читают данные: `POST`, `PUT`, `PATCH` и `DELETE`
возвращают `405`.

## Список бронирований

`GET /api/v1/admin/bookings/`

Возвращает брони всех клиентов платформы.

Параметры запроса:

| Параметр | Значение |
| --- | --- |
| `page` | Номер страницы от 1; по умолчанию 1 |
| `page_size` | Размер страницы от 1 до 100; по умолчанию 20 |
| `status` | `CONFIRMED`, `CANCELLED`, `COMPLETED` |
| `date_from` | Дата `YYYY-MM-DD`: брони, которые заканчиваются после начала этого дня |
| `date_to` | Дата `YYYY-MM-DD`: брони, которые начинаются до конца этого дня |
| `category` | Вид ресурса: `UNIVERSITY_ROOM`, `RESTAURANT_TABLE`, `HOTEL_ROOM` |
| `provider` | `id` менеджера ресурса |
| `client` | `id` клиента |
| `ordering` | `-created_at` (по умолчанию), `created_at`, `start_at`, `-start_at` |

Вместе `date_from` и `date_to` выбирают брони, период которых хотя бы частично попадает
в эти дни. `date_from` не может быть позже `date_to`. Даты считаются в часовом поясе
проекта.

Успешный ответ `200` содержит `count`, `page`, `page_size` и `results`. Каждый элемент
`results` содержит:

| Поле | Значение |
| --- | --- |
| `id` | Идентификатор брони |
| `client` | `id`, `email` и `name` клиента; `name` содержит полное имя или логин |
| `resource` | `id`, `name` и `kind` ресурса |
| `period` | `start_at` и `end_at` брони |
| `status` | Статус брони в том виде, в котором он хранится в базе данных |
| `created_at` | Время создания брони |

## Ошибки

Ошибки имеют единый формат:

```json
{"code": "VALIDATION_ERROR", "message": "Invalid request data.", "details": {}}
```

| HTTP | Код | Когда возникает |
| --- | --- | --- |
| `400` | `VALIDATION_ERROR` | Неверный параметр запроса |
| `403` | `UNAUTHORIZED` | Нет аутентификации |
| `403` | `ACCESS_DENIED` | Нет роли администратора или учётная запись неактивна |
| `405` | `METHOD_NOT_ALLOWED` | Метод запроса не поддерживается |
