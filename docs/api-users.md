# API пользователей для администратора

Все методы доступны только аутентифицированному активному пользователю с ролью `ADMIN`.
Префикс API: `/api/v1/`.

## Список пользователей

`GET /api/v1/admin/users/`

Параметры запроса:

| Параметр | Значение |
| --- | --- |
| `page` | Номер страницы от 1; по умолчанию 1 |
| `page_size` | Размер страницы от 1 до 100; по умолчанию 20 |
| `search` | Поиск по email, логину и имени |
| `role` | `CLIENT`, `MANAGER`, `ADMIN`; `PROVIDER` принимается как `MANAGER` |
| `is_active` | Фильтр по активности: `true` или `false` |
| `ordering` | `-created_at` (по умолчанию), `created_at`, `email`, `-email` |

Успешный ответ `200` содержит `count`, `page`, `page_size` и `results`. Каждый элемент
`results` содержит `id`, `email`, `name`, `role`, `is_active`, `created_at`. Поле `name`
содержит полное имя, а при его отсутствии — логин.

## Карточка пользователя

`GET /api/v1/admin/users/{id}/`

Положительный целочисленный `id` обязателен. Успешный ответ `200` содержит `id`,
`email`, `name`, `role`, `is_active`, `created_at`, `updated_at` и `last_login`.
`last_login` может быть `null`. Пароль и другие секреты не возвращаются.

## Ошибки

Ошибки имеют единый формат:

```json
{"code": "NOT_FOUND", "message": "Requested object not found.", "details": {}}
```

| HTTP | Код | Когда возникает |
| --- | --- | --- |
| `400` | `VALIDATION_ERROR` | Неверный параметр запроса или `id` |
| `403` | `UNAUTHORIZED` | Нет аутентификации |
| `403` | `ACCESS_DENIED` | Нет роли администратора или учётная запись неактивна |
| `404` | `NOT_FOUND` | Пользователь с указанным `id` не найден |
