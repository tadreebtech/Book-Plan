# API клиентского каталога и объявлений поставщика

| Запрос | Доступ | Результат |
| --- | --- | --- |
| `GET /api/v1/listings/` | Аутентифицированный пользователь | Активные объявления со статусом `APPROVED` |
| `GET /api/v1/provider/listings/` | Активный пользователь с ролью `MANAGER` | Собственные объявления, включая неактивные, в статусах `PENDING`, `APPROVED`, `REJECTED` и `HIDDEN` |

Оба запроса поддерживают фильтр `category`, поиск по части названия через `search`
и параметры пагинации `page` и `page_size`. По умолчанию возвращается первая
страница с размером до 20 объявлений. Максимальный размер страницы — 100.
Объявления отсортированы от новых к старым.

Ответ содержит `count` (общее число объявлений после фильтрации), `page`,
`page_size` и `results`. У каждой записи есть `id`, `title`, `category` и
`capacity`. В списке поставщика также доступны `is_active`, `moderation_status`
и `rejection_reason`. Причина заполнена для объявлений со статусом `REJECTED`.
